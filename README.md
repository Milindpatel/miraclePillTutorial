# Miracle Pill

A one-screen UIKit order form from an iOS tutorial. It practises laying out a form in Interface Builder and using a `UIPickerView`: tap the state button, pick one of the 50 US states, and the picker hides and the button shows your choice.

## Running

Open `MiraclePill/MiraclePill.xcodeproj` in Xcode and run it on an iOS 15+ simulator or device. The project uses Swift 5.

CI builds the app for the iOS Simulator on every push.
